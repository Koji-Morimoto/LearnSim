# Isaac Sim 6.2.0 バックエンド学習ラボ

## 目的

Isaac Sim 6.2.0 で、シミュレーションの状態（Stop / Play / Pause）とバックエンド（usd / usdrt / fabric / tensor）の組み合わせごとに、どの API がなぜ使えるのかを、観測できる Snippet とノートで記録する。

## 前提とするバージョン

- Isaac Sim 6.2.0。手元のインストール先は `C:\isaacsim-6.2.0` で、`VERSION` ファイルの値は `6.2.0-rc.14+release.52805.02189a84.gl` である。
- 手元の次の6ファイルは、GitHub の `v6.2.0` タグと改行コード以外一致することを 2026-11-08 に確認した。
  - `isaacsim.core.experimental.utils` の `impl/backend.py`
  - `isaacsim.core.experimental.prims` の `impl/xform_prim.py`、`impl/articulation.py`、`impl/rigid_prim.py`
  - `isaacsim.core.simulation_manager` の `impl/simulation_manager.py`
  - `isaacsim.core.rendering_manager` の `impl/rendering_manager.py`
- GUI は `isaac-sim.bat` から起動し、`apps\isaacsim.exp.full.kit` を使う。

## 表記の約束

- 用語は [用語集](01_用語と概念/01_用語集.md) の定義で使い、同じものを別の語で言い換えない。
- 確度は、表記なし（公式ドキュメントかソースで確認した事実）／（実測）（Isaac Sim を動かして測った結果）で書く。推論や未確認のまま知識として書かない。分からないことが出てきたら、確かめてからノートに書く。
- 数式は表示数式のブロックで書き、説明の文章とは分ける。数式は GitHub と Obsidian の両方で表示される `$$ … $$` の記法で書く。
- 関数とクラスは、コードブロックの外でも `isaacsim.core.simulation_manager.SimulationManager.step()` のような完全修飾名で書く。各ノートの末尾の「このノートに出てくる API の import」に、必要な import 文をまとめる。
- Snippet の解説ノートには、py ファイルと同じコードの全文を、言語に python を指定したコードブロックで載せる。
- リンクは、標準の Markdown 相対リンクで書く。
- 出典は、各ノートの末尾の脚注と、frontmatter の `source` に書く。
- 最終版だけを書き、編集の経緯は書かない。ノートとSnippetの書き方の約束の全体は [学習方針](06_学習方針/01_学習方針.md) にある。

## 追加するときの手順

1. `snippets/` に py ファイルを追加する。既存の Snippet を変えるときは、変更前の版を `C:\isaacsim-6.2.0\CodeByClaude\isaac-sim-backend-lab_old\` の下にフォルダごと残してから書き換える。py ファイルとノートのコードが食い違った場合は、ノートの側を正とし、py ファイルをノートに合わせる。
2. `05_観測Snippet/` に、その Snippet の解説ノートを、そのフォルダの最後の番号の次の番号を付けて追加し、[MOC-観測Snippet](05_観測Snippet/00_MOC-観測Snippet.md) の表に1行足す。
3. 新しい概念のノートは、内容に合うカテゴリのフォルダに、読む順の番号を付けて置き、そのフォルダの MOC の表に1行足す（MOC のないフォルダはこの README の目次を直す）。前後のノートの「前後のノート」の表も直す。
4. 未確認事項が観測で確定したら、[MOC-未確認事項](07_未確認事項/00_MOC-未確認事項.md) の「状態」と、元のノートの記述を直す。
