# 用語集

このリポジトリのノートでは、次の定義で用語を使う。同じものを別の語で言い換えない。

## 状態とバックエンド

| 用語 | 定義 |
|---|---|
| 状態 | timeline の状態を指す。Stop / Play / Pause の3つがある |
| バックエンド | Core Experimental API がデータを読み書きする経路。usd / usdrt / fabric / tensor の4種と、6.2.0 で加わった simstate がある |
| 物理エンジン | 力・拘束・接触を解いて次の状態を計算する本体。PhysX と Newton がある |
| 数値フレームワーク | 計算結果を入れる配列の種類。numpy / torch / warp がある。torch は PyTorch の Python パッケージ名である |
| ラッパー | Core Experimental API の `isaacsim.core.experimental.prims.Articulation`、`isaacsim.core.experimental.prims.RigidPrim`、`isaacsim.core.experimental.prims.XformPrim` などのクラス。1つのラッパーが1個以上のプリムを受け持つ |
| 姿勢 | 位置と向きの組。スケールは含まない |

「backend」という英単語がソースの中で3つの意味に使われている点は、[backendという語の3つの意味](02_backendという語の3つの意味.md) にまとめた。

## view

| 用語 | 定義 |
|---|---|
| view | `omni.physics.tensors` が提供するオブジェクトで、実行中の物理エンジンの内部オブジェクト群をまとめて読み書きする窓口 |
| simulation view | ステージと物理エンジンの組ごとに1つ作られる view の入口 |
| 子の view | simulation view から、プリムのパスを指定して作る view。articulation view、rigid body view、rigid contact view がある |
| physics tensor entity | エラーメッセージに出る語。ラッパーが持つ子の view を指す |

詳しくは [viewとは何か](03_viewとは何か.md) を参照する。

## 時間

| 用語 | 定義 |
|---|---|
| メインループ | Kit アプリケーションが終了まで繰り返し実行する処理の流れ |
| 更新 | メインループの1回分の反復。`omni.kit.app.get_app().update()` の1回にあたる |
| timeline 時刻 | `omni.timeline` が管理する時刻 |
| 物理ステップ | 物理エンジンが物理の状態を刻み幅 h 秒だけ進める1回分の計算 |
| シミュレーション時刻 | 実行済みの物理ステップ数に刻み幅を掛けた時刻 |
| 描画側の時刻 | 描画が参照する時刻。物理ステップのたびにシミュレーション時刻が書き写される |

詳しくは [時間と物理ステップ（「全体像：メインループの1回の更新で起きること」の節）](../03_時間と物理ステップ/01_時間と物理ステップ.md) を参照する。

## 観測の道具

| 用語 | 定義 |
|---|---|
| 環境指紋 | [env_fingerprint.py](../snippets/env_fingerprint.py) が出力する、設定値と状態の一覧 |
| スパイ | 元の関数を包み替えて、呼ばれるたびに中身を表示させる観測用のコード。実装は [backend_spy.py](../snippets/backend_spy.py) にある |
| strict | 2つの raise フラグを True に固定した `isaacsim.core.experimental.utils.backend.use_backend()`。定義は [strict_backend.py](../snippets/strict_backend.py) にある |

## 確度の表記

| 表記 | 意味 |
|---|---|
| （表記なし） | 公式ドキュメントか v6.2.0 のソースで確認した事実 |
| （実測） | Isaac Sim 6.2.0 を実際に動かして測った結果。測った日と方法をノートに書く |

2026-11-08 の版では、ほかに「推論」「【未確認】」「【要観測】」の表記を使っていた。2026-11-09 に、それらの事項はすべてソースか実測で確かめて書き直した（[MOC-未確認事項](../07_未確認事項/00_MOC-未確認事項.md)）。今後も、推論や未確認のまま知識として書かない。

## このノートに出てくる API の import

このノートでは、関数とクラスを `モジュール名.クラス名.メソッド名` の完全修飾名で書いている。Script Editor で使うときは、次の import を先に実行する。import した後は、完全修飾名からモジュール名の部分を除いた名前で呼べる。たとえば `isaacsim.core.simulation_manager.SimulationManager.get_num_physics_steps()` は `SimulationManager.get_num_physics_steps()`、`isaacsim.core.experimental.utils.backend.use_backend()` は `backend_utils.use_backend()` と書く。

Script Editor に貼って実行するコード（ファイルではない）
```python
# このノートに出てくる API の import
from isaacsim.core.experimental.prims import Articulation  # Articulation のラッパー
from isaacsim.core.experimental.prims import RigidPrim  # 剛体のラッパー
from isaacsim.core.experimental.prims import XformPrim  # Xform のラッパー
import isaacsim.core.experimental.utils.backend as backend_utils  # use_backend / get_current_backend などを持つモジュール
import omni.physics.tensors  # view を作るモジュール
import omni.timeline  # timeline のインターフェース
import omni.kit.app  # Kit アプリケーション（メインループ）のインターフェース
```
