# 設定一覧

バックエンドの挙動と時間の進み方を左右する設定を、1つのコードにまとめたノートである。

## このノートで使う用語

| 用語 | 意味 |
|---|---|
| 状態 | timeline の状態。Stop / Play / Pause の3つがある |
| バックエンド | Core Experimental API がデータを読み書きする経路。usd / usdrt / fabric / tensor / simstate がある |
| 物理エンジン | 力・拘束・接触を解いて次の状態を計算する本体。PhysX / Newton がある |
| view | `omni.physics.tensors` が提供するオブジェクトで、実行中の物理エンジンの内部オブジェクト群をまとめて読み書きする窓口 |
| メインループ | Kit アプリケーションが終了まで繰り返し実行する処理の流れ。1回分を「更新」と呼ぶ |
| 物理ステップ | 物理エンジンが物理の状態を刻み幅 h 秒だけ進める1回分の計算 |
| 上限周波数 | メインループが1秒あたりに行う更新の回数の上限。`/app/runLoops/main/rateLimitFrequency` |
| 目標フレームレート | timeline が持つ値。Play 中のメインループの回数を決める |
| 物理の出力先 | 物理エンジンが計算した姿勢を、毎ステップどこへ書き出すか。USD・Fabric・どちらにも書かない、の3通りがある |

ほかの用語の定義は [用語集](../01_用語と概念/01_用語集.md) にまとめている。

## 読み方

下の「設定一覧のコード」を Script Editor に貼って実行すると、各設定の今の値が表示される。コードの中の各設定の直前のコメントに、次の4つを書いた。

1. 何に効くか
2. 既定値（2026-11-09 に GUI とヘッドレスで実測した値。kit ファイルに書かれた値と違う場合は両方）
3. Stop / Play / Pause で値が変わる場合は、その変わり方と、変えているもの
4. 変え方（そのまま実行できるコードを、行頭に `#` を付けて書いた。`#` を外して実行すると変わる）

変えた値は、Isaac Sim を再起動すると元に戻る。ただし `/persistent/` で始まる設定は、ユーザー設定ファイルに保存され、次回の起動に持ち越される。起動時から値を変えたい場合は、`isaac-sim.bat --/app/player/useFastMode=true` のように、起動オプションで `--設定のパス=値` を渡す。

`C:\isaacsim-6.2.0\isaac-sim.bat` は `apps\isaacsim.exp.full.kit` を使って起動する。`isaacsim.exp.full.kit` は `isaacsim.exp.base.kit` の設定の上に、自分の設定を重ねている。

## 設定一覧のコード

Script Editor に貼って実行するコード（ファイルではない。どの状態でもよい）
```python
# 設定一覧：バックエンドの挙動と時間の進み方を左右する設定の、今の値を表示する
# 各設定の直前のコメント：何に効くか／既定値（2026-11-09 の実測）／状態による変化／変え方（# を外すと変わる）
import carb.settings  # Kit の設定を読み書きするモジュール
import omni.kit.app  # 拡張機能の有効・無効を調べるために使う
import omni.timeline  # timeline の値を読み書きするために使う
import omni.usd  # ステージの timeCodesPerSecond を読み書きするために使う
from isaacsim.core.rendering_manager import RenderingManager  # メインループの刻みをまとめて変えるクラス
from isaacsim.core.simulation_manager import SimulationManager  # 物理の出力先・刻み幅・デバイスを扱うクラス
from omni.kit.loop import _loop as kit_loop  # メインループの manual mode を読むために使う

settings = carb.settings.get_settings()  # 設定ストアを取得する
timeline = omni.timeline.get_timeline_interface()  # timeline のインスタンスを取得する
ext_manager = omni.kit.app.get_app().get_extension_manager()  # 拡張機能の管理クラスを取得する
loop_runner = kit_loop.acquire_loop_interface()  # メインループのインターフェースを取得する
has_physics_scene = bool(SimulationManager.get_physics_scenes())  # Physics Scene があるか（ないと get_physics_dt が /PhysicsScene を作ってしまうので、先に調べる）


def show(key: str) -> None:
    """設定のパスと今の値を1行で表示する。"""
    print(f"{key} = {settings.get(key)!r}")  # 値を表示する（キーが存在しなければ None）


print(f"=== 状態: playing={timeline.is_playing()} stopped={timeline.is_stopped()} ===")  # どの状態で読んだかを表示する

print("=== バックエンド ===")
# 【何に効くか】usdrt / fabric バックエンドが使えるか（Fabric Scene Delegate）。false だと use_backend("usdrt") などが RuntimeError を出す
# 【既定】True（base.kit）
# 【注意】isaacsim.core.experimental.utils.backend モジュールが読み込まれたときに1回だけ読まれる。起動後に変えても use_backend の判定は変わらない（実測）
# 【変え方】起動オプション --/app/useFabricSceneDelegate=false
show("/app/useFabricSceneDelegate")

# 【何に効くか】物理の計算結果（姿勢）を Fabric に直接書くか（omni.physx.fabric 拡張）
# 【既定】無効（full.kit は依存に書いていない。GUI で実測）。isaacsim.exp.full.fabric.kit で起動すると有効
# 【変え方】SimulationManager.enable_fabric(True) で有効にし、下の4つの updateToUsd 系を false にする。enable_fabric(False) で元に戻す
# SimulationManager.enable_fabric(True)
print(f"omni.physx.fabric enabled = {ext_manager.is_extension_enabled('omni.physx.fabric')}")

# 【何に効くか】物理の計算結果を、毎ステップ USD の属性に書き戻すか（姿勢・速度・パーティクル・力覚センサー）
# 【既定】True / True / True / None（GUI で実測。None は設定がないことを表し、拡張の既定値が使われる）
# 【影響】USD に書かない構成では、Play 中に XformPrim（usd）で読む姿勢が Play 前の値のまま変わらない。剛体 1000 個で、USD へ書くと更新1回 66 ms、4つとも書かないと 6.2 ms（実測）
# 【変え方】4つまとめて変えるなら SimulationManager.enable_fabric(...)。個別に変えるなら次の行
# settings.set_bool("/physics/updateToUsd", False)
show("/physics/updateToUsd")
show("/physics/updateVelocitiesToUsd")
show("/physics/updateParticlesToUsd")
show("/physics/updateForceSensorsToUsd")

# 【何に効くか】Stop したときに、物理の状態を Play 前に戻すか
# 【既定】True（base.kit）。/persistent/ なので、UI で変えた値が次回の起動に持ち越される
# settings.set_bool("/persistent/physics/resetOnStop", False)
show("/persistent/physics/resetOnStop")

# 【何に効くか】Play / Stop のときに、SimulationManager が view の作成と無効化を行うか
# 【既定】True（拡張の既定）
show("/exts/isaacsim.core.simulation_manager/enable_default_callbacks")

# 【何に効くか】tensor の背後で動く物理エンジン（PhysX / Newton）
# 【既定】'physx'（拡張の既定）
# 【変え方】SimulationManager.switch_physics_engine("newton")（isaacsim.physics.newton 拡張が必要）
show("/exts/isaacsim.core.simulation_manager/default_engine")
print(f"active engine = {SimulationManager.get_active_physics_engine()!r}")

# 【何に効くか】物理に使う GPU の番号と、GPU から CPU へ結果を読み戻さないか
# 【既定】-1 / False（GUI で実測）
# 【影響】tensor のデータが GPU（cuda）に置かれるのは suppressReadback が true のときだけ。false なら、物理を GPU で計算していても（Physics Scene の enableGPUDynamics が true でも）データは CPU に置かれる（ソース）
# settings.set_bool("/physics/suppressReadback", True); settings.set_int("/physics/cudaDevice", 0)
show("/physics/cudaDevice")
show("/physics/suppressReadback")
print(f"physics device = {SimulationManager.get_physics_sim_device()!r}")

# 【何に効くか】Articulation の DOF の目標値・力を simstate にも書くか（disabled / mirror / exclusive）
# 【既定】None（設定がなく disabled として扱われる）
# 【注意】simstate の書き込み先（isaacsim.mega.sim_state.client）は 6.2.0 のインストールに含まれない。mirror ではエラーのログが出るだけ、exclusive では目標値がどこにも書かれなくなる（実測）
# settings.set_string("/isaacsim/articulation/simStateMode", "disabled")
show("/isaacsim/articulation/simStateMode")

print("=== 時間の進み方 ===")
# 【何に効くか】更新のたびに物理ステップを実行するか。Play したときに SimulationManager が view を作るかもこの値で決まる
# 【既定】True（GUI で実測）
# 【影響】Play 中に false にすると timeline だけが進む。true に戻しても、進まなかった分は取り戻さない（実測）
# settings.set_bool("/app/player/playSimulations", False)
show("/app/player/playSimulations")

# 【何に効くか】true なら、1回の更新で timeline を 1/C 秒（C は timeCodesPerSecond）進める。false なら、メインループの刻みだけ進める
# 【既定】True（full.kit）。base.kit は False
# settings.set_bool("/app/player/useFixedTimeStepping", False)
show("/app/player/useFixedTimeStepping")

# 【何に効くか】固定刻みで、メインループの回数が C より多いときも、毎回 timeline を進めるか（false なら間引く）
# 【既定】False（GUI で実測）
# 【影響】C = 30 のとき、false ならメインループ2回に1回だけ timeline と物理が進む。true なら毎回進み、シミュレーションは実時間の2倍の速さになる（実測）
# settings.set_bool("/app/player/useFastMode", True)
show("/app/player/useFastMode")

# 【何に効くか】メインループの更新回数に上限をかけるか
# 【既定】True（full.kit）。base.kit は False
# settings.set_bool("/app/runLoops/main/rateLimitEnabled", False)
show("/app/runLoops/main/rateLimitEnabled")

# 【何に効くか】上限周波数。1回の更新がこの逆数の秒数より早く終わったら、残りを待つ
# 【既定】120（omni.kit.loop-isaac の extension.toml）。full.kit のコメントにある「既定 60」とは違う
# 【状態による変化】Play を押すと timeline が目標フレームレート（既定 60）に書き換え、Pause・Stop で元の値に戻す（実測。Stop 中に 200 にすると Play 中は 60、Pause・Stop の後は 200）
# 【変え方】Stop / Pause 中の値は次の行。Play 中の回数は、下の目標フレームレートで変える
# settings.set_float("/app/runLoops/main/rateLimitFrequency", 120.0)
show("/app/runLoops/main/rateLimitFrequency")

# 【何に効くか】Play 中のメインループの回数。実際の回数は C の倍数に丸められる（timeline のヘッダ ITimeline.h）
# 【既定】60（実測）
# 【影響】目標 120・C 60 なら Play 中は1秒に120回、目標 30・C 60 なら60回（実測）
# timeline.set_target_framerate(120)
print(f"timeline target framerate = {timeline.get_target_framerate()}")

# 【何に効くか】メインループを manual mode（更新ごとの時間の進みを固定の刻みにする）で回すか
# 【既定】False（Stop・Pause 中）、True（Play 中）。full.kit と base.kit には true と書かれているが、拡張機能 isaacsim.core.throttling が
#        /exts/isaacsim.core.throttling/enable_manualmode = true のとき、起動時と Pause・Stop で無効にし、Play で有効にする（ソースと実測）
# 【影響】固定刻み（useFixedTimeStepping = true）のときは、manual mode の有無で timeline の進みは変わらない（実測）
show("/app/runLoops/main/manualModeEnabled")
show("/exts/isaacsim.core.throttling/enable_manualmode")
print(f"loop manual mode = {loop_runner.get_manual_mode()}, manual step size = {loop_runner.get_manual_step_size()}")  # manual mode の刻みの既定は 1/60 秒（RunLoopRunner.cpp と実測）

# 【何に効くか】描画をメインループと別のスレッドで行うか
# 【既定】True（Stop・Pause 中）、False（Play 中）。isaacsim.core.throttling が、/exts/isaacsim.core.throttling/enable_async = true のとき、
#        Play で false にし、Pause・Stop の10回後の更新で true に戻す（ソースと実測）
# 【影響】true の間は、描画フレームのイベント（NEW_FRAME）が2回ずつまとめて届くことがある
show("/app/asyncRendering")
show("/exts/isaacsim.core.throttling/enable_async")

# 【何に効くか】1回の更新で実行する物理ステップの回数の上限（Steps per Second ÷ この値。切り捨て、最低1）。0 なら上限なし
# 【既定】30（実測）。ステージを新しく作ったり開いたりすると 30 に戻る（実測）
# 【影響】上限を超えた分は「上限 × 刻み幅」までしか持ち越されず、超えた分は捨てられて、シミュレーションが timeline から遅れ続ける（ソースと実測）
# settings.set_int("/persistent/simulation/minFrameRate", 0)
show("/persistent/simulation/minFrameRate")

# 【何に効くか】ステージの timeCodesPerSecond（記号 C）。固定刻みのとき、1回の更新で timeline を 1/C 秒進める
# 【既定】ステージごと（新しいステージは 60）
# omni.usd.get_context().get_stage().SetTimeCodesPerSecond(30); timeline.set_time_codes_per_second(30)
print(f"stage timeCodesPerSecond (C) = {omni.usd.get_context().get_stage().GetTimeCodesPerSecond()}")

# 【何に効くか】Physics Scene の Steps per Second（記号 S）。物理の刻み幅 h = 1/S
# 【既定】Physics Scene ごと（Physics Scene がなければ 60）
# SimulationManager.set_physics_dt(1.0 / 120.0)
if has_physics_scene:  # Physics Scene がある場合だけ読む
    print(f"physics dt (h) = {SimulationManager.get_physics_dt()}")
else:  # ない場合は
    print("physics dt (h) = Physics Scene がないため表示しない")

# 【まとめて変える API】RenderingManager.set_dt(dt) は、上限周波数を 1/dt にし、manual mode の刻みを dt にして manual mode を有効にし、
#                      timeline の目標フレームレートとステージの timeCodesPerSecond も 1/dt に揃える（ソースの docstring と公式ドキュメント）
# RenderingManager.set_dt(1.0 / 30.0)
print(f"RenderingManager.get_dt() = {RenderingManager.get_dt()}")  # rateLimitEnabled が true なら 1 / 上限周波数、false なら manual mode の刻み（manual mode のとき）、どちらでもなければ 1 / 上限周波数（ソース）

print("=== ログ ===")
# 【何に効くか】ログ全体・端末・ログファイルに出す最低のレベル（verbose / info / warn / error / fatal）
# 【既定】Info / Warning / Info（実測）
# 【影響】Play 中、Isaac Sim 自身はログをほとんど出さない（剛体 100 個の Play 中の 300 回の更新で 0 バイト）。レベルを error にしても更新の速さは変わらなかった（実測）
# settings.set_string("/log/level", "error")
show("/log/level")
show("/log/outputStreamLevel")
show("/log/fileLogLevel")
show("/log/file")

# 【何に効くか】Script Editor のログ欄が保つ最大の行数。行数が多いほど、print 1回あたりの時間がかかる
# 【既定】1000（omni.kit.window.script_editor の extension.toml）。ログ欄が作られたときに1回だけ読まれるので、変えるときは起動オプションで渡す
# 【変え方】起動オプション --/exts/omni.kit.window.script_editor/maxLogLines=200
show("/exts/omni.kit.window.script_editor/maxLogLines")
```

## 状態によって値が変わる設定のまとめ

上のコードを Stop・Play・Pause で実行すると、次の4つが状態によって変わる（2026-11-09 に GUI とヘッドレスで実測）。どれも、それぞれの状態に切り替わったときに、Kit の timeline か拡張機能 isaacsim.core.throttling が書き換えている。

| 設定 | Stop | Play | Pause | 書き換えているもの |
|---|---|---|---|---|
| `/app/runLoops/main/rateLimitFrequency` | 120 | 60（目標フレームレート） | 120 | timeline |
| `/app/runLoops/main/manualModeEnabled` | False | True | False | isaacsim.core.throttling |
| `/app/asyncRendering` | True（10回後） | False | True（10回後） | isaacsim.core.throttling |
| `RenderingManager.get_dt()` | 0.00833 | 0.01667 | 0.00833 | 上の2つの結果 |
