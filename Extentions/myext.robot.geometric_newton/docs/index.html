myext.robot.geometric_newton ドキュメント

物理ソルバ不要の幾何ロボット制御＋Newton 1.6.1 自前コリジョン空間（0 フレーム遅延）の完全自己完結ドキュメント群です。

拡張機能の全体像とドキュメント案内

適用ステージ前提（単位規約）： 本拡張は metersPerUnit=1 のステージ専用です。長さ・距離・直動関節位置はすべて m（metersPerUnit=1 のステージ専用）、速度は m/s として扱います（ステージの metersPerUnit による自動換算は行いません）。

myext.robot.geometric_newton は、物理ソルバや Drive を使わずに関節値から全リンクの姿勢を計算して描画しつつ、Newton 1.6.1 の内部 FK（eval_fk）と自前コリジョン空間（GeometricScene / CollisionPipeline）により、write_target="fabric" のまま Stop / Play=ON の両方で 0 フレーム遅延の干渉判定・めり込み深さ・クリアランス計測 を実現する拡張機能です。

最短クイックスタート（パフォーマンス最優先の基本形）

既存 USD ロボットへ IsaacRobotAPI が付与されていれば、from_articulation() を呼ぶだけで構成要素（GeometricRobotComponent）が自動生成されます。毎フレームのホットループでは事前取得した Component へ NumPy 配列を渡し、複数アームの更新は batch_update() で 1 回に集約します。

from myext.robot.geometric_newton import GeometricRobot # 既定値: collision_mode="none", write_target="fabric", collision_backend="newton", # limit_policy="clip", convex_meshes=True, auto_components=True, # merge_variant_components=False, debug_draw_colliders=False robot = GeometricRobot.from_articulation(stage, "/World/Robot") print(robot.describe()) # 構成要素・全 DOF・mimic・VariantSet を整形 JSON で確認 # 事前バインドした Component を使って高速に部分更新（multi-arm の例） arm0 = robot.get_component("arm0") arm1 = robot.get_component("arm1") with robot.batch_update(): arm0.set_dof_positions(q_arm0) # FK + Fabric 書込を遅延 arm1.set_dof_positions(q_arm1) # ブロック終了時に 1 回だけ実行 # USD フラッシュ不要・0 フレーム遅延で干渉とめり込み深さ（m / metersPerUnit=1 専用）を取得 pairs = robot.check_collisions() # リミット到達・超過している子リンクを取得（着色・警告表示に利用） limit_links = robot.get_limit_violation_links() # デバッグ時だけ Newton 内部コライダー形状 (シアン / 干渉=赤 / 接触点=オレンジ) を可視化 robot.debug_draw_colliders = True
