GeometricLayer / Options / Report / authoring

GeometricLayer は、元の USD ファイル（Root Layer）を一切変更せずにロボットを幾何モードへ切り替えるための USD Sublayer 管理クラスです。layer_target="session"（既定）ではメモリ上の Session Layer に匿名サブレイヤーとして差し込まれるため、remove() または robot.close() を呼ぶだけで元の PhysX Articulation 構成へ完全に復元されます。

LocalPoseSolver と 3 種類の TransformWriter

FK が出力する全リンクのワールド行列 (L, 4, 4) を、Isaac Sim のシーングラフへ書き込む層です。リンク Prim の親子階層構造と親スケールを正確に吸収するため、LocalPoseSolver が階層順のローカル変換を計算し、選択された GeometricTransformWriter 実装が書き込みます。

クラス対象バックエンド書込内容・速度特性・注意点
LocalPoseSolver 共通（solve(world) / local_matrices(world) / refresh()） USD 階層上の親 Prim（ロボット外の親を含む）の変換とスケール（world_scales）をキャッシュし、ワールド行列を各リンク Prim のローカル変換へ高速分解する。外部で親 Prim を動かした後は refresh() で再同期。
GeometricFabricWriter write_target="fabric"（既定・CPU 経路） USDRT / Fabric の omni:fabric:worldMatrix（Gf.Matrix4d、行ベクトル規約へ転置して書込）を直接更新し、FSD 経由で Hydra 描画へ反映する。初回タグ付け時に omni:fabric:localMatrix を削除して IFabricHierarchy による上書きを防止する。補助メソッド read_world() で Fabric から現在姿勢を逆読込できる。
GeometricGpuFabricWriter write_target="fabric" かつ use_gpu_fabric_writer=True Warp GPU カーネルで Newton の body_q_wp（GPU 配列）から Fabric GPU バッファの worldMatrix 配列へ直接書き込む。CPU-GPU 同期コピーを排した大規模バッチ最速経路。
GeometricUsdWriter write_target="usd" / "both" および flush_to_usd() 幾何 Sublayer 上の xformOp:transform:geometric を Sdf.ChangeBlock 一括トランザクションで書き込む。USD 変更通知が発火するため Fabric 経路より重いが、USD ベース機能（PhysX / Show by Type / Stage 保存）と完全同期する。

model.transforms 座標規約・全 13 関数

本拡張の統一数学規約（全モジュール共通）：
・同次変換行列：形状 (4, 4) float64 の列ベクトル規約（並進成分は第 4 列 T[:3, 3]、点の変換は p_world = R @ p_local + t）。USD / Fabric（行ベクトル規約、並進は第 4 行）との境界では writer.py / usd_reader.py 内で必ず転置して相互変換する。
・四元数（Quaternion）：すべて スカラー先頭 (w, x, y, z)（単位四元数）。Newton / Warp の内部形式 (x, y, z, w) との変換は newton_backend.py 内で完結しており、公開 API は一貫して (w, x, y, z)。
・import 方法：from myext.robot.geometric_newton import transforms でも from myext.robot.geometric_newton.model import transforms でも同一モジュールを取得できる。
