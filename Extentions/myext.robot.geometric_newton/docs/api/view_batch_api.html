GeometricRobotView バッチ API

同一構造の N 台ロボットを一括制御・GPU FK・CUDA Graph 衝突判定・GPU Fabric 直接書込するバッチ API の完全仕様（metersPerUnit=1 のステージ専用）。

GeometricRobotView 生成・from_articulations

GeometricRobotView は、同一の運動学構造（is_kinematically_equal）を持つ N 台のロボットをまとめて制御・FK・干渉判定するバッチ API です。入力と出力は先頭次元がロボット台数 N の配列（例：(N, D)）となり、BatchedNewtonScene と CUDA Graph を用いて全 N 台を 1 回のカーネル起動で処理します（長さ・距離はすべて m、metersPerUnit=1 のステージ専用）。

バッチ関節操作・姿勢取得・干渉判定

取得系メソッドの戻り値型（Isaac Sim Experimental Articulation 互換）： get_dof_positions・get_dof_position_targets・get_dof_limits・get_world_poses・get_link_world_poses は wp.array（float32, device="cpu"） を返します（NumPy 配列が必要な場合は .numpy() を呼ぶ）。get_dof_indices・get_joint_indices・get_link_indices は wp.array（int32） です。NumPy float64 を直接返すのは get_link_world_matrices() のみです。
メソッドシグネチャ入出力形状・戻り値型・動作

get_dof_positions / get_dof_position_targets (*, indices=None, dof_indices=None, unit=None) wp.array（形状 (K, M), float32, device="cpu"）。
get_dof_limits (*, indices=None, dof_indices=None, unit=None) (lower, upper)。各 wp.array（形状 (K, M), float32, device="cpu"）。
get_world_poses / set_world_poses get_world_poses(*, indices=None)

get_link_world_poses / get_link_world_matrices get_link_world_poses(*, indices=None, link_indices=None)

sync_environment (*, use_fabric="auto") 共通環境障害物の最新姿勢を BatchedNewtonScene へ同期。

状態共有・入力規約・GPU ゼロコピー・構造変更

View と単体ロボットの状態共有・大規模バッチ最速設定：
・GeometricRobotView と配下の単体ロボット（view.robots[i]）は状態を共有するため、view.robots[i].set_dof_positions(...) と View 側のバッチ操作を混在させても整合が保たれます。
・16 台以上の大規模バッチでは fk_backend="newton"（または "auto"）+ write_target="fabric" + use_cuda_graph=True + use_gpu_fabric_writer=True で GPU ゼロコピー経路が有効になります。
配下ロボットでの VariantSet 切替について： GeometricRobotView に属するいずれかのロボットで set_variant() 等により structure_version が変化すると、次の View 操作時に GeometricStructureChangedError が送出されます。構成変更後は新しいロボット構造で GeometricRobotView を再生成してください。
