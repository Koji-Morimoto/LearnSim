Model / USD Reader / IK / 指令変換 API

NumPy 完結の GeometricRobotModel 全 18 メソッド、UsdArticulationSource と IsaacRobotAPI 自動検出、DH/MDH/Screw/URDF、KinematicChain・IK、指令変換コンバータの完全仕様（metersPerUnit=1 のステージ専用）。

GeometricRobotModel・Spec データクラス

myext.robot.geometric_newton.model 配下は NumPy のみで完結し、Isaac Sim・OpenUSD・Warp・Newton のいずれにも依存しません。オフライン軌道計画や単体テストでそのまま利用できます（長さ・直動関節の単位は m、metersPerUnit=1 のステージ専用）。

GeometricMimicSpec / GeometricJointSpec / GeometricLinkSpec不変データクラス（NumPy のみ）
@dataclass(frozen=True) class GeometricMimicSpec: reference_joint: str # 親となる参照関節名 multiplier: float = 1.0 offset: float = 0.0 # q_dep = multiplier * q_ref + offset @dataclass(frozen=True, eq=False) class GeometricJointSpec: name: str joint_type: Literal["revolute", "prismatic", "fixed"] parent_link: str child_link: str parent_frame: np.ndarray = field(default_factory=tf.identity) # (4, 4) 親リンク座標での関節座標系（既定: 単位行列） child_frame: np.ndarray = field(default_factory=tf.identity) # (4, 4) 子リンク座標での関節座標系（既定: 単位行列） axis: tuple[float, float, float] = (0.0, 0.0, 1.0) # 関節座標系で表した単位回転/直動軸（自動正規化） lower_limit: float = -np.inf # revolute: rad / prismatic: m（metersPerUnit=1 のステージ専用） upper_limit: float = np.inf mimic: GeometricMimicSpec | None = None prim_path: str | None = None # プロパティ: is_dof -> bool, メソッド: replaced(**changes) -> GeometricJointSpec @dataclass(frozen=True) class GeometricLinkSpec: name: str prim_path: str | None = None

ロボットのリンク・関節・Mimic 関係を表す不変定義です。回転関節は rad、直動関節は m（metersPerUnit=1 のステージ専用）を内部統一単位とします。関節変換式は X_wc = X_wp @ parent_frame @ motion(q) @ inv(child_frame) で、Newton の eval_fk と数学的に完全一致します。parent_frame・child_frame の既定値は 4×4 単位行列、axis は関節座標系で表した向きです。

GeometricRobotModel プロパティ一覧不変運動学モデル
model = GeometricRobotModel( name: str, links: Sequence[GeometricLinkSpec], joints: Sequence[GeometricJointSpec], root_link: str | None = None, components: dict[str, tuple[str, ...]] = {}, )

木構造（分岐・複数アーム対応）の剛体リンク連鎖を保持し、幅優先トポロジカル順の FK・Mimic 解決・ヤコビアン計算・直列鎖抽出・モデル合成を提供します。

DH / MDH / Screw / URDF / USD Prim ビルダー

DH / MDH / Screw の共通規約（命名・オフセット・座標系）：
・生成される名前：リンク名は link0（根）〜link{n} と末尾の tool。関節名は各行の name（省略時は joint1, joint2, ...）と末尾の固定関節 tool_fixed。
・DHRow / MDHRow の関節変位：回転関節は theta + q、直動関節は d + q として計算される（theta / d は q=0 のときのオフセット）。
・base / tool / tool_home：いずれも形状 (4, 4) の同次変換行列（None なら単位行列）。
・ScrewAxisRow：direction は単位ベクトル（自動で正規化）。回転関節の moment は point × direction（直動関節では未使用）。軸は q=0 のときの根リンク座標系で与える。軸上の 1 点と向きから作れる ScrewAxisRow.through(point, direction, ...) が便利。

KinematicChain / IK ソルバー群

chain = KinematicChain.from_model(model, base_link: str, tip_link: str, tip_offset=None) # フィールド/プロパティ: base_link, tip_link, variable_names, dof_indices, lower_limits, upper_limits, num_variables, num_joints, has_mimic # メソッド: joint_values(x), forward_kinematics(x), jacobian(x), pose_and_jacobian(x), clip(x), to_model(), to_urdf() @dataclass(frozen=True) class IKSolverConfig: active_dof_mask: Sequence[bool] | None = None orientation_mode: Literal["full", "none"] = "full" position_tolerance: float = 1e-5 # m（metersPerUnit=1 のステージ専用） orientation_tolerance: float = 1e-4 # rad max_iterations: int = 200 num_restarts: int = 20 damping: float = 1e-2 # Levenberg-Marquardt 減衰係数 orientation_weight: float = 1.0 respect_limits: bool = True random_seed: int = 0 @dataclass(frozen=True) class IKResult: dof_positions: np.ndarray # 独立変数の解ベクトル（chain.variable_names 順・常に rad / m） success: bool position_error: float # m（metersPerUnit=1 のステージ専用） orientation_error: float # rad iterations: int = 0 message: str = "" register_ik_solver(name: str, cls) -> None available_ik_solvers() -> list[str] create_ik_solver(name: str, chain: KinematicChain, config: IKSolverConfig | None = None) -> IKSolver # IKSolver 共通メソッド: set_config(**changes), set_active_dofs(mask_or_names), get_active_dofs(), solve(target_position, target_orientation=None, *, seed=None) -> IKResult

任意 2 リンク間の直列運動学鎖に対して減衰最小二乗法（Levenberg-Marquardt: JacobianIKSolver、既定・外部依存なし）または IKPySolver（要 ikpy）で逆運動学を解きます。

副作用・前提・落とし穴利用・自作時の必須規約：
1) apply=False の手動反映：IKResult.dof_positions は robot.angle_unit が何であっても常に rad（直動は m）であるため、robot.set_dof_positions(res.dof_positions, dof_indices=solver.chain.dof_indices, unit="rad") で反映する。
2) apply=True の挙動：res.success == True のときだけロボットへ反映される。
3) target_orientation：(w, x, y, z) の四元数または 3×3 回転行列を受け付ける。
4) set_active_dofs()：名前で指定する場合は chain.variable_names の中の名前を渡す。
5) 自作ソルバーの実装：IKSolver を継承し、__init__(self, chain, config=None)（基底で self.chain と self.config が設定される）と solve(target_position, target_orientation=None, *, seed=None) -> IKResult を実装して register_ik_solver() で登録する。solve() へ渡される目標姿勢は chain.base_link 座標系。

GeometricCommandConverter 群

クラスコンストラクタ主要引数変換式・制約・用途
GeometricCommandConverter (input_names, output_dofs, output_angle_unit="rad") 抽象基底クラス。自作する場合は to_dof_positions(command)（input_names 順の np.ndarray、形状 (..., 入力数) → 形状 (..., 出力数)）を実装。逆変換できない場合は from_dof_positions() で NotImplementedError を送出する。
LinearCommandConverter (input_names, output_dofs, matrix, offset=None, output_angle_unit="rad") 線形変換 q = matrix @ cmd + offset。逆変換できるのは matrix の階数（rank）が入力数に等しいときだけ（それ以外は NotImplementedError）。
InterpCommandConverter (input_name, output_dofs, table_inputs, table_outputs, output_angle_unit="rad", output_for_inverse=None) 1 次元区分線形補間テーブル。table_inputs は 2 個以上で単調増加、table_outputs は形状 (K, 出力数)。範囲外入力は両端値に切り詰める。逆変換に使う output_for_inverse（出力 DOF 名）の列は単調でなければならない。
FunctionCommandConverter (input_names, output_dofs, forward, inverse=None, output_angle_unit="rad") 任意の Python 関数 forward(cmd_vec) -> dof_vec を登録。inverse=None のとき逆変換は NotImplementedError。
