1. CPU / GPU ノード分割と PCIe 境界の意味

Isaac Sim 6.2.0 の性能と挙動を理解するうえで最も重要なのが、どのノードが CPU（Host RAM）にあり、どのノードが GPU（VRAM）にあるかという境界です。特に Fabric と Physics Engine は内部で CPU 側と GPU 側の両方を持ちます。

Fabric (CPU Mirror) と Fabric (GPU Mirror)

Fabric (CPU Mirror) と Fabric (GPU Mirror) は別メモリ空間にあり、Fabric 内部の cpuValid / gpuValid の dirty bits で管理されます。片側でしか触らない属性は反対側へメモリ割当すら行わず、反対側が読んだ瞬間だけ PCIe コピーが発生します。

Physics [CPU] と Physics [GPU/CUDA]

Timeline & Kit Loop [CPU] が PLAY の間、CPU パイプラインは Host RAM 側で演算し、GPU Dynamics / Newton Warp は VRAM 側で並列演算します。/physics/suppressReadback は GPU→CPU の PCIe Readback 経路そのものを遮断するインターロックです。

Tensor API [GPU Direct] と GPU Interop

GPU Dynamics や Newton 実行時、Tensor API [GPU Direct] は USD Stage・Fabric・PCIe を一切通らず VRAM 内の物理バッファへ直結します。さらに physics/fabricUseGPUInterop を ON にすると、PhysX GPU → Fabric GPU も VRAM 内で直接コピーされます。

USD Stage [CPU]・ Editor UI・ Hydra

USD Stage と Editor UI は常に CPU 側に存在します。GPU 側で更新された Fabric (GPU Mirror) の値を Property Window（CPU）から ext."omni.kit.property.usd".enableAdapter で表示すると、Dirty-bit ミラー経由で GPU→CPU の PCIe 読戻しが発生する点に注意が必要です。

4. 現場でよく起きる 5 つの回路トラブル（再現ボタン付）

トラブル①：Viewport では物体が落ちるのに、Property Window や pxr.Usd が動かない（T2実測）

/physics/fabricEnabled が ON・/physics/updateToUsd が OFF では USD Stage が凍結（T2 実測: 5.0m 固定・Notice 0回）します。UI 確認には ext."omni.kit.property.usd".enableAdapter を ON にするか、必要時に save_to_usd() を実行します。

トラブル②：/physics/updateToUsd=True なのに USD Stage が全く更新されない（T4実測）

GPU Dynamics ＋ /physics/suppressReadback が ON だと PCIe Readback 自体が遮断されます（T4 実測: GPU Tensor 3.81462m に対し USD 5.0m 固定・Notice 0回）。GPU 描画には T9 のように GPU Interop 経由で Fabric (GPU Mirror) へ流します。

トラブル③：PLAY 中で物理計算は進んでいるのに Viewport 上の物体が止まったまま（T3実測）

/physics/updateToUsd と /physics/fabricEnabled が両方 OFF だと描画出力が断線します（T3 実測: USD・Fabric ともに 5.0m 固定のまま、Tensor API のみ 3.96995m へ落下）。

トラブル④：USD Stage を書き換えた直後に Fabric (IFabricHierarchy) を読むと古い値になる（T6実測）

FSD 有効時は ② DIRTY 遅延バッチ同期のため、USD 編集直後はまだ Fabric へ反映されていません（T6 実測: 編集直後 5.0m → SynchronizeToFabric() 実行後に 9.0m）。

トラブル⑤：render=False にすると Camera / RTX Lidar が止まる一方、PhysX Sensors は動く（T7実測）

Render Gate を閉じると Hydra → RTX Renderer (GPU) の PCIe 描画給電が止まり 13.2 倍高速化（T7 実測: 12.58 ms vs 165.47 ms）しますが、RTX 系センサーも止まります。Contact / IMU などの PhysX Sensors は物理直結のため動作し続けます。
